# Public release manifest

Release owner: `seefreewind`

## Included

- Core Python, R and shell scripts for phases 1A, 1D, 2A, 2AR, 2BR and 3A.
- Dataset and locus manifests with source identifiers, sample-size conventions and checksums.
- Final derived LDSC, SUPERGNOVA, PLACO+, locus-consolidation, robustness, functional-annotation and fine-mapping-readiness tables.
- Phase reports, decision records, audit tables and derived figures.

## Excluded

- Raw and harmonized GWAS summary-statistics files.
- 1000 Genomes, SUPERGNOVA, Pan-UKBB and other LD/reference files.
- Full PLACO+ genome-wide output (`PLACO_PLUS_GENOMEWIDE.tsv`, approximately 6.9 GB in the source workspace).
- Pair-run outputs, raw SUPERGNOVA outputs, sign-flip summary-statistic files and local logs.
- Private paths, credentials, local environments and manuscript/submission materials.

## Data-use statement

The public release does not replace the original data providers. Source datasets must be downloaded from their original locations and used according to the applicable consortium, repository and citation requirements. Checksums in `config/` identify the source versions used for the frozen results.
